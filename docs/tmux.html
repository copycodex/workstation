tmux — сессии и окна

Всё начинается с префикса Ctrl-a: нажать, отпустить, затем клавишу команды. Пока tmux ждёт вторую клавишу, в статус-баре горит красный PREFIX — не горит, значит префикс не поймался.

рядом: шпаргалка по nvim →

Модель: три уровня, не больше

Вложенных окон в tmux не бывает. Иерархия ровно такая, и «проект с подпроектами» ложится на неё как сессия с окнами.

сервер ──┬── сессия demo-code ──┬── окно 4 «app» ──┬── панель 1
         │                    │                  └── панель 2
         │                    └── окно 5 «docs»
         └── сессия demo-git ─── окно 4 «app» ─── панель 1 (lazygit)

Сервер живёт в фоне отдельно от терминала. Закрытие окна терминала, падение X и logout убивают только клиента — сессии остаются. Не переживает лишь перезагрузку машины.

Вход в работу

ws
Поднять все проекты и открыть дерево выбора
ws demo-code
Сразу в конкретную сессию
ws -l
Что описано и что уже запущено
tmux ls
Список живых сессий
tmux attach -t demo-code
Вернуться в сессию
tmux attach -d -t demo-code
Вернуться, отцепив зависший терминал

Терминал при открытии сам спрашивает Открыть tmux? — Enter соглашается, n оставляет обычный шелл.

Сессии

Ctrl-a→s
Дерево сессий и их окон — главный способ переключаться
Ctrl-a→(/)
Предыдущая / следующая сессия
Ctrl-a→$
Переименовать текущую сессию
Ctrl-a→d
Detach — уйти, всё продолжает работать
tmux new -s ИМЯ
Новая сессия вручную
tmux kill-session -t ИМЯ
Убить одну сессию со всеми окнами
tmux kill-server
Убить вообще всё и начать с чистого листа
Detach — не выход. Ctrl-a d оставляет процессы работать, а exit закрывает панель; закрытие последнего окна убивает сессию. Убить сессию можно и из дерева — клавишей x на её строке.

Окна = проекты

Ctrl-a→1…9
Окно по номеру
Ctrl-a→'→10
Двузначный номер — цифровых биндов только девять
Ctrl-a→n/p
Следующее / предыдущее окно
Ctrl-a→w
Список окон выбором
Ctrl-a→f
Найти окно по имени
Ctrl-a→c
Новое окно
Ctrl-a→,
Переименовать окно
Ctrl-a→&
Закрыть окно — спросит y/n

Панели = процессы

Панель — ещё один терминал внутри окна, открывается в том же каталоге. Мышь включена: можно кликать по панели и тянуть границу.

Ctrl-a→-
Разделить горизонтально — одна под другой
Ctrl-a→|
Разделить вертикально — рядом
Ctrl-a→hjkl
Переход между панелями
Ctrl-a→z
Зум — панель на весь экран и обратно
Ctrl-a→HJKL
Менять размер — можно жать подряд
Ctrl-a→;
Туда-обратно между двумя последними
Ctrl-a→q
Показать номера панелей
Ctrl-a→x
Закрыть панель — спросит y/n
Ctrl-a→!
Вынести панель в отдельное окно

Прокрутка и копирование

Ctrl-a→Enter
Войти в режим копирования — в нём работает прокрутка и вимовые движения
v
Начать выделение
y
Скопировать в системный буфер и выйти
Esc
Выйти без копирования
